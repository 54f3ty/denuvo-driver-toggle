### Features
- One-click driver installation (select your own .sys file)
- Real-time status monitoring (installed / running)
- Easy service toggle (ON/OFF)
- Clean, minimal dark-themed interface

### Requirements
- Windows (tested on Windows 10/11)
- **.NET Framework 4.8** or higher (usually pre-installed on modern Windows; download from Microsoft if needed)

### Usage
1. Download the release.
2. Run `DriverToggle.exe`
3. Use the "Install Driver" button → select your .sys file.
4. Toggle the service ON/OFF as needed.
5. Monitor the status indicator.

Always refer to the original instructions/source for your hypervisor crack/driver setup — this tool only simplifies the driver loading/unloading part.
